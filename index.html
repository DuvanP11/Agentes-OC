    Setup

    Recursos y paquetes para OpenCode

    Todo lo necesario para que el ecosistema funcione bien en macOS y Windows.

    Paquete instalable

    Cómo instalar todo

    Este repo incluye las definiciones reales de los 56 agentes (7 primarios + 49 subagentes), un instalador para macOS, Linux y Windows y, ahora, la oficina pixel para ver al equipo trabajando. No borra tus agentes existentes: hace backup y fusiona.

    1

    Clona el paquete

    Descarga el repo con las definiciones y los instaladores.

    git clone https://github.com/DuvanP11/Agentes-OC.git ~/dev/Agentes-OC
    cd ~/dev/Agentes-OC
    2

    Instala los 56 agentes

    El instalador crea un backup de tu config y agrega los agentes sin sobrescribir los tuyos.

    # macOS / Linux
    bash install.sh

    # Windows
    powershell -ExecutionPolicy Bypass -File install.ps1
    3

    Verifica

    Confirma que todos los agentes quedaron cargados en tu OpenCode.

    opencode agent list
    4

    Instala la oficina nuevo

    Necesita Node 20+. Descarga Agent-Office, lo compila y agrega el plugin. Luego reinicia OpenCode una vez.

    # macOS / Linux
    bash oficina/instalar.sh
    ~/.agentes-oc/oficina/oficina

    # Windows
    powershell -ExecutionPolicy Bypass -File oficina\instalar.ps1

    🤖 O autoinstalación con un prompt (Claude Code u OpenCode)

    Pega este prompt en Claude Code o en OpenCode (en la máquina nueva): detecta el SO, instala lo que falte, clona el repo, ejecuta el instalador, agrega el plugin de memoria, el MCP docling y la oficina pixel, y verifica el resultado.

    Actúa como instalador del paquete Agentes-OC. Ejecuta este plan completo y verifica cada paso con evidencia real (salida de comandos):

1. DETECTA el sistema operativo (macOS, Windows o Linux) con uname o ver.
2. VERIFICA e INSTALA los prerrequisitos que falten: git, node (LTS), python3, jq, gh (GitHub CLI).
   - En macOS usa Homebrew (brew install ...). Si Homebrew no existe, instálalo.
   - En Windows usa winget (winget install ...).
   - En Linux usa el gestor nativo (apt/dnf/pacman).
   No instales nada que ya esté instalado. Muestra qué instalaste y qué ya existía.
3. VERIFICA si OpenCode está instalado (opencode --version). Si no, instálalo con el instalador oficial (macOS/Linux: descarga a /tmp y ejecuta con bash; Windows: instalador de PowerShell). Verifica con opencode --version.
4. CLONA el repo https://github.com/DuvanP11/Agentes-OC.git en ~/dev/Agentes-OC (si ya existe, haz git pull).
5. EJECUTA el instalador de agentes: macOS/Linux bash install.sh, Windows powershell -ExecutionPolicy Bypass -File install.ps1. Verifica que el backup se creó y que opencode.json contiene los agentes.
6. INSTALA el plugin de memoria: opencode plugin @cioffi_ai/opencode-memory.
7. INSTALA el MCP docling si es posible (pip install docling-mcp-server).
8. INSTALA la oficina pixel para ver al equipo: lee primero oficina/instalar.sh (Windows: oficina\instalar.ps1) y resume qué hará; luego ejecútalo. Necesita Node 20 o superior. Arráncala con ~/.agentes-oc/oficina/oficina start (Windows: oficina.ps1 start en %USERPROFILE%\.agentes-oc\oficina) y verifica que http://127.0.0.1:4099/health responde y que existe ~/.config/opencode/plugins/pixel-office.ts.
9. VERIFICA el resultado final: opencode agent list debe mostrar director, fullstack-product-engineer, security-engineer, security-reviewer y los demás. Cuenta cuántos agentes quedaron instalados.
10. ENTREGA un resumen final con: SO detectado, prerrequisitos instalados, versión de OpenCode, número de agentes instalados, estado de la oficina y cualquier paso que requiriera acción manual. Recuerda al usuario reiniciar OpenCode y abrir http://127.0.0.1:4099/?demo=0 para ver a su equipo.

Regla de seguridad: no ejecutes nada destructivo, no borres configuraciones existentes sin backup, y si un paso requiere sudo/administrador pídelo al usuario.

    🏢 Solo la oficina, con ayuda de Claude Code u OpenCode

    Si ya tienes los agentes instalados y solo quieres ver la oficina, pega este prompt.

    Actúa como instalador de la Oficina pixel de Agentes-OC (https://github.com/DuvanP11/Agentes-OC). Verifica cada paso con la salida real de los comandos:

1. DETECTA el sistema operativo.
2. VERIFICA que existan git y Node 20 o superior (node -v). Si falta alguno, dime qué comando lo instala (macOS: brew install git node · Windows: winget install Git.Git OpenJS.NodeJS.LTS) y pide mi permiso antes de instalarlo.
3. CLONA el repo en ~/dev/Agentes-OC (si ya existe, haz git pull).
4. LEE oficina/instalar.sh (Windows: oficina\instalar.ps1) antes de ejecutarlo y resúmeme en 3 líneas qué va a hacer.
5. EJECÚTALO: macOS/Linux bash oficina/instalar.sh · Windows powershell -ExecutionPolicy Bypass -File oficina\instalar.ps1
6. ARRANCA la oficina: ~/.agentes-oc/oficina/oficina start (Windows: powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\.agentes-oc\oficina\oficina.ps1" start).
7. VERIFICA: http://127.0.0.1:4099/health responde, existe ~/.config/opencode/plugins/pixel-office.ts y http://127.0.0.1:4099/assets/nombres.json trae los nombres del equipo.
8. INDÍCAME que reinicie OpenCode una vez y abra http://127.0.0.1:4099/?demo=0 (en VS Code: Simple Browser: Show). Cuando lo haya hecho, ejecuta ~/.agentes-oc/oficina/oficina status y confirma que aparece mi sesión.

Reglas: no borres ni sobrescribas configuraciones (el instalador respalda lo que reemplaza), no modifiques opencode.json, no muestres tokens ni claves, y si algo pide sudo/administrador, pregúntame primero.

    Archivos del paquete: agents/ (56 definiciones JSON + MD) · install.sh · install.ps1 · scripts/export-agents.sh (regenera el paquete desde tu OpenCode) · oficina/ (plugin, web e instaladores de la oficina pixel).
